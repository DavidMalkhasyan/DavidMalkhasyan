## About me

I'm a full-stack developer based in **Yerevan, Armenia**, working primarily with **JavaScript, TypeScript, React, and Node.js**.

My path into software engineering started with **C programming and computer architecture**, which shaped my interest in how software works beneath the interface. I enjoy turning product requirements into working systems: designing APIs, modeling data, building user interfaces, and testing the behavior that connects them.

- **Focus:** Full-stack development, backend engineering, and API design
- **Interests:** PostgreSQL, transactions, concurrency, system design, and Linux
- **Currently learning:** Java, deeper backend architecture, and AI-assisted engineering workflows
- **Approach:** Understand the trade-offs, build the simplest reliable solution, and verify it with tests
